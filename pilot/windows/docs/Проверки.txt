DADO HOME — проверка тестового комплекта, 24.09.2026

Успешно выполнено:
- Сборка backend .NET 8: 0 ошибок, 0 предупреждений.
- Проверка TypeScript и production-сборка React/Vite.
- Миграции на пустой PostgreSQL и проверка готовности базы.
- Интеграционные тесты API: матрица ролей, чужие чеки, смена роли,
  отключение сотрудника, откат продажи, недостаточная оплата, повторные
  запросы, конкурентная продажа последней единицы и конкурентный возврат,
  отложенный чек (создание/обновление/проведение/отмена), отчёт и аудит.
- Запуск self-contained Windows-приложения из папки через Windows PowerShell.
- Панель и API доступны через один адрес, без отдельного Node-сервера.
- Вход пяти тестовых ролей, каталог из восьми товаров, продажа и возврат.
- Повторный запуск без второго экземпляра приложения.
- Остановка/повторный запуск: чеки, остатки, пароли и идемпотентность сохранены.

Выявлено ограничение: PostgreSQL initdb не поддерживает кириллицу в пути
в этой сборке. Запускатель проверяет путь заранее; используйте C:\Dado-Home-Pilot.

Проверка проводилась на текущем Windows-компьютере; отдельная чистая
виртуальная машина Windows и физическое кассовое оборудование не проверялись.
Тесты доступны в Исходники.zip: tests/pos.integration.mjs и tests/pilot.windows.mjs.
