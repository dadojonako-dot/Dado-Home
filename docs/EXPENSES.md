# Расходы магазина

Раздел «Расходы» хранит фактические затраты в TJS: дата, категория, сумма с точностью до 0,01 и описание. Доступны фильтры по датам включительно и категории, общий итог по всему фильтру и страницы по 50 записей.

Администратор вносит и отменяет расходы. Финансы имеет только просмотр; Кассир, Менеджер заказов и Служба поддержки доступа не имеют. Права проверяются API. Отмена требует причины, сохраняет запись и исключает её из суммы. Исправление — отмена и новая запись. Создание и отмена записываются в аудит в одной транзакции с расходом. Повтор запроса с тем же UUID не создаёт дубль; иное содержимое с тем же UUID даёт 409.

Это журнал учёта: он не выполняет банковские платежи, не изменяет складские остатки и не уменьшает наличные POS-смены. Закупку товаров следует отдельно отразить в складском учёте. Категории пока фиксированы. Вложения и регулярные автоматические расходы не реализованы.

API: GET /api/admin/expenses/categories; GET /api/admin/expenses?from=2026-09-01&to=2026-09-30&category=Аренда&page=1; POST /api/admin/expenses с id/date/amount/category/description; POST /api/admin/expenses/{id}/cancel с reason.

Проверка на отдельной пустой PostgreSQL БД: задать POS_TEST_CONNECTION и DOTNET, собрать backend, выполнить node tests/expenses.integration.mjs. Тест запускает и останавливает собственный API на 5190.
